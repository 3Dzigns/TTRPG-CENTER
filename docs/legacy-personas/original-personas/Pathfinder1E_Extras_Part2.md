# Pathfinder 1E Extra Personas (Part 2)

## 4. Elena (she/her) — Spanish Catholic GM, Madrid — *Pathfinder 1E*

- **English Q:** How do archetypes change class features?
- **English A:** They replace or modify base abilities listed. Because archetypes are trade-offs for flavor.
- **Spanish Q:** ¿Cómo cambian los arquetipos las características de clase?
- **Spanish A:** Reemplazan o modifican habilidades básicas. Porque los arquetipos son intercambios por sabor.

- **English Q:** What’s the easiest way to speed up initiative?
- **English A:** Pre-roll NPCs and track with cards. Because initiative overhead slows play.
- **Spanish Q:** ¿La forma más fácil de acelerar la iniciativa?
- **Spanish A:** Tira de antemano PNJs y usa cartas. Porque la iniciativa puede ralentizar la partida.

- **English Q:** How do prestige classes interact with archetypes?
- **English A:** They stack unless they replace the same class features. Because rules prevent double replacement.
- **Spanish Q:** ¿Cómo interactúan las clases de prestigio con los arquetipos?
- **Spanish A:** Se combinan salvo que reemplacen la misma habilidad. Porque las reglas evitan reemplazo doble.

- **Russian Q:** Как работают проверки концентрации?
- **Russian A:** Бросьте d20 + уровень заклинателя + модификатор против СЛ. Потому что заклинания срываются при потере концентрации.
