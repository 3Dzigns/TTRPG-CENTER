## Root Cause Analysis

**Primary Issue:**
**Critical Python Indentation Error** in `src_common/toc_parser.py`

1. **Indentation Defect at Line 112**
   - **Problem**: Function `_extract_text_with_timeout` defined at module level (indent 0) instead of class method level (indent 4)
   - **Cause**: Incorrect indentation breaks Python class definition
   - **Result**: All subsequent methods after line 112 are not attached to TocParser class

2. **Class Definition Breakage**
   - **Problem**: Python class definition is broken by incorrect indentation
   - **Cause**: Module-level function definition inside what should be class scope
   - **Result**: TocParser instances have no methods available at runtime

3. **Method Attachment Failure**
   - **Problem**: Methods like `parse_document_structure`, `_find_and_parse_toc` not attached to class
   - **Cause**: Class definition terminated early due to indentation error
   - **Result**: AttributeError when attempting to call any class methods

**Technical Root Cause:**
The function `_extract_text_with_timeout` on line 112 of `toc_parser.py` is incorrectly indented at column 0 instead of column 4, making it a module-level function instead of a class method. This breaks the Python class definition, preventing all subsequent method definitions from being attached to the TocParser class.

**1. Fix Critical Indentation Error**
```python
# INCORRECT (line 112):

    def _extract_text_with_timeout(extract_func, timeout_seconds: float) -> str:
```
